# Wallcraft NC — сайт для Тильды

- `tilda/wallcraft-v1.html` — вся страница (макет V1 Ochre Editorial). Копируется целиком в блок Тильды **T123 «HTML-код»**.
- `images/` — фото и видео страницы. Подключаются через CDN:
  `https://cdn.jsdelivr.net/gh/ekhorolskaia-jpg/wallcraft@main/images/<файл>`

Чтобы фото показывались, репозиторий должен быть **публичным**, а изменения — в ветке `main`.
